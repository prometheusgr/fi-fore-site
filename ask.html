We don't track you, so tell us

fi-fore counts nobody. The app has no analytics and this site has no trackers, cookies or counters. So the only way we learn what to build is that you tell us.

Why we don't watch

Trust. Someone monitoring what you do and how you do it is creepy; if a person did that in real life, we would call the police. Software doing it quietly is no different. So we use only what a household chooses to tell us.

How to ask

A feature gets built because someone asked. Write to alex@fi-fore.com with a feature you want or a problem you hit. Any mail client and any address works; there is no account, no form and no sign-up. The same address is behind "Request a feature or report a problem" in the app, which adds only the app version and your operating system to the mail.

A person reads it and writes back. There is no public list of requests and no voting: a count invites ranking by volume, and "I want this too" is one more mail you choose to send.

Who carries the mail

alex@fi-fore.com goes through Cloudflare Email Routing, which forwards it to the owner's mailbox. Your address stays in that mailbox: never in an issue, on this site or in the source.

What we can't turn off

GitHub counts downloads of the installers, and we can't switch that off. We don't read the count. GitHub Pages, which hosts this site, keeps its own server logs.
