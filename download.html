How to verify

Each release lists the SHA-256 of every installer in SHA256SUMS, signed with Sigstore (SHA256SUMS.sigstore.json). Compare the hash of your download with its line in that file.

Windows (PowerShell):

Get-FileHash -Algorithm SHA256 .\fi-fore-X.Y.Z.exe

macOS:

shasum -a 256 fi-fore-X.Y.Z.dmg

To also check that fi-fore’s release build signed the list, install cosign and run the cosign verify-blob command shown under “Verify this release” in the release notes.
